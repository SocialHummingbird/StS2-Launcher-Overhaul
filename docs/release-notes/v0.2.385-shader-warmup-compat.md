## What Changed

- Adds an Android shader warmup compatibility plan for large shader sets.
- Bumps shader warmup status markers to `Warmup version: 7`.
- Uses a bounded Android warmup plan for large shader sets: batch size `1`, render target `128` materials, then `completed-partial` with startup continuing.
- Adds a smaller crash-recovery warmup when the previous marker stopped during rendering, rendering-batch, or watchdog-warning.
- Records render plan, target material count, batch size, previous-render-crash suspicion, scanner counts, and completion classification in `last_shader_warmup_status.txt`.
- Keeps the local tester package identity so existing current tester installs can update in place.

## Known Caveats

- This is still prerelease/tester software.
- ARM64 Android hardware is the current proof target.
- Android x86_64 emulator behavior is diagnostic-only and is not game-launch proof.
- Workshop/mod support remains beta-quality.
- `completed-partial` means startup continued with degraded shader-cache coverage; it is not the same as full shader precompile completion.
- Some devices may still be below the practical support floor. If startup fails before `completed-partial`, attach focused logcat and `last_shader_warmup_status.txt` where available.
