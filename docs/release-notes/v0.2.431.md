# v0.2.431 — Launcher improvements and reliable startup

This ARM64 release combines the launcher improvements and launch-cycle refactor with the FMOD/PCK validation fixes from the previous published v0.2.430 release.

## Changes

- Reorganized launcher navigation, actions, and status messages; content fits narrow screens without horizontal scrolling.
- Help can open a GitHub bug report prefilled with redacted diagnostic information.
- The launcher checks for newer GitHub releases and offers verified in-app APK downloads followed by Android's installation confirmation.
- Game loading has one owned startup task, scene-specific readiness, rendered-frame confirmation, and acknowledged durable Android restart requests.
- Timed-out preparation cannot overlap another launch or file operation. Stalled save cleanup stops launch safely. Removed competing force-load recovery, unused code, and the warmup finish delay.
- Retains the previous release's production-shaped FMOD/PCK validation and managed Android preparation ownership fixes.

## Installation

- APK: `StS2Launcher-v0.2.431-arm64-v8a.apk`
- Package: `com.sts2launcher.overhaul.fork.local`
- Version: `0.2.431` / version code `431000`
- Architecture: `arm64-v8a`
- Signing channel: existing local/tester channel, matching the previous local APKs.

Install over the existing matching application with Android's Update action or `adb install -r`. Saves, credentials, mods, and installed game versions stay in place. This is not an APK for a differently named or differently signed release-channel package.

The APK includes no Steam game files. SHA-256 checksum and build metadata are attached alongside the APK.
