## What Changed

- Fixes the public-beta modded launch path so selected manifest-backed Android mods are not rejected into the previous scan/load failure route.
- Keeps public-beta launch tied to the matched beta PCK plus matched beta managed runtime pack.
- Preserves runtime-pack validation for non-public branches.
- Keeps the Android BaseLib compatibility bypass for known incompatible patch classes.
- Adds launcher-side compatibility behavior for the manually imported SavesMerger path.
- Keeps focused package logs and validation wrapper checks strict enough that fallback/gating is not counted as success.

## Mod Support Status

Mod support is real but still beta-quality.

Workshop discovery can stage supported subscribed items, and selected mods can be loaded through the Android runtime mod-loader path. Some Workshop items are still exposed by Steam only as legacy UGC handles without a direct Android-usable content source. Those items may need manual import.

The highest-priority mod remains `Vanilla and Modded Saves Merger`. It now has manual-import selection/scan evidence on Android, but full real-save merge behavior across user save states is not signed off.

## Steam Cloud Safety

- Pull from Steam Cloud is the safer first action.
- Push to Steam Cloud is never automatic.
- Manual Push remains guarded because it can overwrite Steam Cloud saves.
- Push remains locked while active modded-save risk states are present.
- No Push to Cloud was performed during this validation.

## Known Issues

- Launcher UI scaling/scrolling is still a top user-facing issue on unusual displays and foldables.
- Controller input is not fully validated across Odin, Thor, and similar Android handhelds.
- Some devices may struggle during first-run shader compilation.
- Some subscribed Workshop items may show as needing manual import.
- SavesMerger needs broader real-save compatibility reports.
- Steam beta password/private branch entry is not release-ready.
