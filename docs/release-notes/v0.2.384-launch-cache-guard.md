## Unofficial Project Notice

This is an unofficial community launcher for running your own Steam copy of Slay the Spire 2 on ARM64 Android. It is not affiliated with, endorsed by, sponsored by, or supported by Mega Crit Games, Steam, or Valve.

No Slay the Spire 2 game files, assets, music, art, or Workshop content are bundled. Steam ownership is required.

This release should be treated as prerelease tester software, not an official mobile port or sanctioned replacement for any future official mobile version.

## What Changed

- Publishes the Android launch-readiness/startup crash guard validated on connected ARM64 hardware.
- Keeps the current local tester package line so existing tester installs can update without changing package identity.
- Preserves the existing public-beta/runtime-pack hardening path and bounded shader warmup work from earlier releases.

## Validation Boundary

- Validated locally on ARM64 Android hardware before publication.
- Public-beta launch reached the Slay the Spire 2 main menu with matched beta PCK/runtime evidence.
- `NativeFallbackActivity` was not treated as a successful launch.
- Steam Cloud Push was not run during validation.

## Known Caveats

- This is still prerelease/tester software.
- ARM64 Android hardware is the current proof target.
- Android x86_64 emulator behavior is diagnostic-only and is not game-launch proof.
- Workshop/mod support remains beta-quality.
- Shader warmup can still expose weak-device GPU/memory limits; shader reports need focused logcat plus `last_shader_warmup_status.txt` where available.
