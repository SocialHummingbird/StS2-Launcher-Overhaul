# StS2 Launcher v0.2.428

**UNVERIFIED ANDROID CANDIDATE — CURRENT-SOURCE DEVICE VALIDATION NOT PERFORMED**

This is an experimental ARM64 prerelease. It is not a stable, phone-ready, or
release-ready build.

## What changed

- Simplified Home around the selected game version, launch mode, save namespace,
  and one contextual Play action.
- Made save synchronization states and manual directions explicit without
  implying that vanilla and modded saves are merged.
- Simplified Versions around the game version Play will use.
- Simplified Mods around Vanilla/Modded selection, enabled toggles, and one
  truthful runtime result per mod.
- Made Help recovery-first, with Safe Start primary and diagnostics secondary.
- Removed repeated global launcher state, filler labels, and status labels
  derived from arbitrary prose.
- Restored the existing Android main-menu preparation and startup-task lifetime
  guard.
- Retained the opt-in deferred-preload experiment for a later one-device
  comparison. Normal loading remains the default.

## Offline validation

The attached APK passed:

- .NET Release build with zero errors.
- Focused local-save, synchronization, mod-selection, version-selection, and

- Compact and desktop screenshot-free launcher interaction tests.
- Fresh desktop Vanilla, disabled, and active importer fixtures.
- APK content and Android crypto-patch verification.
- Package, version, signer, update-continuity, and ARM64-only ABI inspection.
