## What changed

- The final installed `SlayTheSpire2.pck` and source `sts2.dll` now define authoritative game identity. Old runtime-pack or cache evidence cannot override current files.
- Steam branch updates revoke readiness before mutation and publish a new ready identity only after verified completion.
- Runtime packs and the Android active assembly cache use staged validation and atomic promotion/rollback.
- Recovery/redownload targets only the selected branch and preserves saves, credentials, Workshop content, and other branch installations. The old bulk **Remove old versions** action is absent.
- Launcher handoff is attempt-bound: only the active attempt's main-menu readiness, foreground state, and focus can dismiss its overlay. Late or duplicate callbacks cannot complete another launch.

## Install

Install the APK over the existing `com.sts2launcher.overhaul.fork.local` application. Choose **Update** in Android, or use `adb install -r <apk-path>`. Do not uninstall or clear application data first; those actions remove application-private local saves.

## Validation

The exact release APK installed in place and passed 10/10 counted launches on Samsung `SM-F971B`, Android 17 / API 37:

- Four cold launches.
- Four warm launches.
- One background/resume during handoff.
- One lock/unlock during handoff.

Every attempt had a unique ID; exactly one readiness, overlay-hidden, and handoff-completed event; matching game identity/runtime-pack/patch validation; a visible foreground game; no remaining launcher overlay; and no stale completion. ## Limits

Broad device/GPU/branch/mod compatibility, fresh Steam authentication, live Steam save transfer, and a physical interruption test at every update checkpoint are not claimed.
