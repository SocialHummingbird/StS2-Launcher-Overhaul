## Mod Support Status

Mod support remains beta-quality.

The latest strict modded public-beta evidence still proves selected/scanned `BaseLib`, `Quick Restart 2`, and manually imported `Vanilla and Modded Saves Merger` with `playMode=modded`, `scannedRoots=3`, and `enabledMods=3`. That is loading/scanning evidence, not full save-merge signoff.

The highest-priority mod test remains whether `Vanilla and Modded Saves Merger` makes existing vanilla/modded saves visible and loadable across real user save states.

## Known Issues

- SavesMerger real-save usability is not signed off.
- Controller input needs in-game device-specific proof.
- Weaker devices may still stall or crash during shader compilation.
- Some Workshop items still expose only legacy UGC handles and may need manual import.
- Launcher UI is usable in current validation but still needs polish for a cleaner mobile-first experience.
- Core-release currently behaves like public unless Steam exposes a distinct core-release payload.

## Steam Cloud Safety

- Pull from Steam Cloud first.
- Push to Steam Cloud is never automatic.
- Manual Push remains guarded because it can overwrite Steam Cloud saves.
- Do not use Steam Cloud Push during modded-save testing unless you intentionally want to upload the tested Android save state.
