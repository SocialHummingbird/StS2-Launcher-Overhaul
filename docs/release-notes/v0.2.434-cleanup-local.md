# v0.2.434-cleanup-local — Launch repairs and code cleanup

This ARM64 release repairs existing launch paths and removes duplicate launcher implementations. It is published at the user's request after local validation. The affected phone was unavailable; the original Modded title-screen freeze remains unverified.

## Changes

- Startup factories run outside state locks, late tasks stay observed, preload fallback preserves ordering and accounting, and diagnostics can capture evidence without relying on the blocked game thread.
- The existing handoff owner now holds attempt-bound menu readiness. Launch preferences and recovery cleanup stay in their existing controller and recovery owners.
- Reports capture each diagnostic marker once, avoiding repeated reads and mixed evidence. Runtime and mod identity hashing use the existing SHA-256 implementation.
- Authentication retries, mod-result validation, discovery snapshots and Android restart decisions use their existing owners. The unused silent native sound subsystem is removed.
- 301 source fragments are consolidated into 63 responsibility files. Launch contracts, persisted formats, save namespaces, credential storage and mod selection are preserved.

Install over the matching app using Android's Update action or `adb install -r`. Keep application data: no uninstall or reset is required. The APK includes no Steam game files. Checksum and build metadata are attached.

## Validation

- 154 managed tests, 56 Android/JVM tests and 12 deterministic save-safety scenarios passed. These suites were rerun before publication.
- The existing real-resource preload probe, phone/desktop launcher interaction profiles and representative mod fixtures passed during cleanup validation. These are desktop checks, not Android gameplay proof.
- The exact APK passed ARM64 contents, Android crypto and update-identity verification. Its checksum is unchanged from the audited candidate.
- A fresh final code review found no actionable issues. The [cleanup report](https://github.com/SocialHummingbird/StS2-Launcher-Overhaul/blob/v0.2.434-cleanup-local/docs/system-cleanup-2026-10-02.md) separates implementation consolidation, deleted scaffolding, file-only changes and retained compatibility paths.
