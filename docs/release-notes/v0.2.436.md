# v0.2.436 - Original mod framework on Android

Workshop packages now load through the game's original mod framework. The launcher downloads and selects complete packages; the game reads their manifests, checks dependencies, sets the load order and runs their initializers. Packages do not need launcher-specific edits.

## Changes

- Keep complete Workshop packages, including companion files and secondary assemblies. A failed update leaves the previously committed package available.
- Use Steam's subscription and version-selection contracts to select the package revision.
- Show the game's loading results for the actual game, runtime, package contents and enabled selection. A changed setup makes older results stale.
- Replace individual-mod workarounds with shared Android runtime fixes. The original loader and model construction are restored; named initializers, skipped patch lists, blanket assembly publicizing and activation guesses are removed. Mono and Harmony are built from pinned source.

## Recorded verification

Before publication, the merged source passed 220 managed tests and 56 Android/JVM tests. ARM64 runtime contracts passed. Phone testing used candidate **436008** and covered unmodified Workshop gameplay, secondary scripts, room restart, saving and reloading after process termination, stale-result handling and Vanilla isolation. After those checks, all 403 current game/save/settings files were restored byte for byte, preserving newer user progress.

The published APK, **436009**, was built from commit `33abc177097fe55bd2c630756f55ecd5e7a60ef8`. It passed contents, Android crypto, signing and in-place update compatibility checks against v0.2.435 and candidate 436008. This final APK has not been installed on a phone; the gameplay observations above concern candidate 436008.

Managed analyzers passed. Android lint reported the same 15 errors and 39 warnings as the previous main branch, with no new findings. No GitHub CI checks ran. x86_64 execution, physical-mouse behaviour and the separate long-run stability procedure were not verified.
