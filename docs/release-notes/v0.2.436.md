# v0.2.436 - Original mod framework on Android

Workshop packages now load through the game's original mod framework. The launcher selects complete physical packages; the game owns manifests, ordering, dependencies, loading, initialization and errors.

## Changes

- Restore the original loader and model construction. Remove named-mod initializers, skipped patch lists, assembly publicizing and activation guesses.
- Build the shared Mono and Harmony runtime from pinned source, with corrections for Android patching, assembly access and initialization behaviour.
- Preserve complete Workshop generations and the previous installation when an update fails. Match Steam's subscription and version-selection contracts.
- Report native loading results for the actual game, runtime, package contents and selection. Background status checks preserve newer user choices.

## Verification

The merged source passes 220 managed tests and 56 Android/JVM tests. ARM64 runtime contracts and physical candidate testing cover unmodified Workshop gameplay, secondary scripts, room restart, cold save/reload, status invalidation and Vanilla isolation. After device testing, all 403 current game/save/settings files were restored byte for byte, preserving newer user progress.

This release APK passes contents, Android crypto, signing and in-place update checks against both v0.2.435 and candidate 436008. It is rebuilt from commit 33abc177097fe55bd2c630756f55ecd5e7a60ef8. Physical testing used candidate 436008; the final release APK (436009) has not been installed on a phone because no device is currently connected.

Managed analyzers pass. Android lint has the same 15 errors and 39 warnings as the previous main branch, with no new findings. No GitHub CI checks ran. x86_64 execution, physical-mouse behaviour and the separate long-run stability procedure remain outside this verification.
