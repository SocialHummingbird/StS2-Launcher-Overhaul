## What Changed

- Replaced the single long launcher workflow with stable Home, Saves, Versions, Mods, and Help destinations.
- Added bottom navigation for phones and constrained top navigation for wide/foldable layouts.
- Removed ready-path control reparenting, automatic task re-anchoring, and the former sticky workflow strip.
- Added Android full-sensor launcher orientation with sensor-landscape game startup, safe-area-aware composition, and responsive confirmation, Steam Guard, and diagnostics layouts.
- Preserved existing download, launch, branch, mod, repair, diagnostics, Pull, and guarded Push event routing.

## Validation

- Exact ARM64 APK installed over existing app data on Samsung `SM-F966B` and reported version code `398031`.
- Deterministic preview matrix passed 20 phone portrait, phone landscape, foldable, and desktop viewport cases.
- Accessibility names, focusability, viewport bounds, minimum target heights, event routing, and no-final-Cloud-Push contracts passed.

Final unlocked physical portrait/landscape capture did not run because the device disconnected after installation. This release therefore does not claim complete exact-build cover/inner viewport or real game-handoff evidence.

## Requirements And Limitations

- You must own Slay the Spire 2 on Steam. The APK contains no game files, assets, saves, or Workshop content.
- ARM64 Android hardware is the current game-launch target. Android x86_64 remains diagnostic-only.
- The APK uses package `com.sts2launcher.overhaul.fork.local`, internal version `0.2.398-launcher-ui-redesign-local`, version code `398031`, and the repository's local test signing channel.
- Steam version selection, Workshop/mod behavior, SavesMerger compatibility, controller input, and confirmed Steam Cloud Push remain hardening areas.
- Pixel 10 Pro / Android 17 / PowerVR issue #34 is not fixed by this release. The reporter tested `v0.2.397`, reached real `NMainMenu`, and exited before the first post-startup probe. The leading cause is the Godot 4.5.1 OpenGL Compatibility PowerVR transform-feedback shader-cache bug documented in [Godot issue #113911](https://github.com/godotengine/godot/issues/113911) and fixed for all PowerVR devices by [Godot PR #111329](https://github.com/godotengine/godot/pull/111329), included in Godot 4.5.2.

Back up saves and Pull from Steam Cloud before considering any Push operation.
