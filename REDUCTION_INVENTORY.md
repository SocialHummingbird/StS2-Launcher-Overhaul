## Authority and disposition

Retain keeps the existing owner. Repair changes its implementation. Replace routes every caller to an existing owner and deletes the superseded implementation. Remove deletes unreachable code or production no-ops. File consolidation does not change responsibility.

## Apparent duplicates retained

An exact-body scan reviewed 1,383 managed method bodies of at least 40 tokens. Bootstrap branch hashing had an existing equivalent API and was replaced. Remaining groups:

- Workshop path checks protect different download/staging mutation roots; each boundary still validates its own root. No generic path-policy owner is introduced.
- Workshop Log methods deliver different instance events. An event adapter would not remove a competing decision owner.

Managed/native authorization, game-file readiness, source selection, startup lifetime, scene provenance, credential platform implementations and save/transfer separation remain distinct responsibilities. The former mod discovery/readiness caches and staging move/rollback layer have been removed; unrelated retained boundaries keep their recorded reasons.
